# 🤝 Contributing to AI Analytics Agent

Thank you for your interest in contributing to the AI Analytics Agent project!

Contributions, suggestions, bug reports, and improvements are welcome.

## 📌 How to Contribute

Follow these steps to contribute to this project:

1. Fork this repository.
2. Clone your fork to your local machine.
3. Create a new branch for your changes.
4. Make your changes to the project.
5. Test your changes to ensure they work correctly.
6. Commit your changes with a clear commit message.
7. Push your branch to your forked repository.
8. Open a Pull Request describing your changes.

## 💡 Areas for Contribution

You can contribute in the following areas:

- Improving the n8n workflow.
- Enhancing AI-powered data analysis.
- Improving Google Sheets integration.
- Adding useful analytical questions.
- Improving data validation and quality checks.
- Enhancing email reports and formatting.
- Improving project documentation.
- Fixing bugs and suggesting new features.

## 🛠️ Contribution Guidelines

Please follow these guidelines when contributing:

- Keep changes relevant to the project's objectives.
- Write clear and descriptive commit messages.
- Test workflow changes before submitting them.
- Update the documentation when necessary.
- Explain the purpose of your changes in your Pull Request.
- Ensure that examples and analytical results are accurate.

## 🔐 Security and Privacy

- Never commit API keys, passwords, or access tokens.
- Do not share private Google Sheets data.
- Remove credentials and sensitive information from exported n8n workflows.
- Use sample or anonymized datasets when appropriate.
- Do not upload confidential or personally identifiable information.

## 🐛 Reporting Bugs

When reporting a bug, please include:

- A clear description of the problem.
- Steps to reproduce the issue.
- The expected behavior.
- The actual behavior.
- Relevant screenshots or error messages, with sensitive information removed.

## 🚀 Suggesting New Features

Feature suggestions are welcome.

Please explain:
- The problem the feature would solve.
- How the feature could work.
- How it would improve the AI Analytics Agent.

## 📄 Code of Conduct

Be respectful, constructive, and professional when interacting
with other contributors.

Harassment, abusive behavior, and disrespectful communication
are not acceptable.

## 🙌 Thank You

Thank you for helping improve the AI Analytics Agent!

Every useful contribution helps make this project better.
